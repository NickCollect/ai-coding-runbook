GLM 5.3 is Z.ai's latest open-weight coding model and the successor to [GLM 5.2](https://cursor.com/docs/models/glm-5-2.md). It supports a 1M-token context window and three reasoning levels (Low, High, and Max), with High as the default. Add it to the model picker from **Cursor Settings > Models**. For a faster, lower-cost option from the same family, see [GLM 5.3 Flash](https://cursor.com/docs/models/glm-5-3-flash.md).

## Hosting

GLM 5.3 is an open-weight model from Z.ai. Cursor serves it through our inference partners. Learn more about [where models are hosted](https://cursor.com/docs/models-and-pricing.md#faq) or see the full list of [sub-processors](https://trust.cursor.com/subprocessors).

## Pricing

Cursor [plans](https://cursor.com/docs/models-and-pricing.md) include two usage pools. GLM 5.3 draws from the third-party **Other Models** pool, which charges at the rates below. All prices are per million tokens.

GLM 5.3 bills at the same per-token rates as GLM 5.2. Pricing is flat across the full context window, with no long-context surcharge and no separate cache-write fee.

DeepSeek V4.1 Flash 1017 is an open-weight coding model from DeepSeek. It supports a 1M-token context window and five reasoning levels (None, Low, Medium, High, and Max), with High as the default. It does not take image inputs. Add it to the model picker from **Cursor Settings > Models**.

# Разработка полнофункциональных приложений в Google AI Studio

Google AI Studio теперь поддерживает полный цикл разработки, позволяя создавать приложения, которые выходят за рамки клиентских прототипов. С помощью серверной среды выполнения вы можете управлять секретами, подключаться к внешним API и создавать многопользовательские игры в реальном времени.

## Среда выполнения на стороне сервера

Теперь приложения Google AI Studio могут включать серверный компонент (Node.js).
Эта функция позволяет:

- **Выполнять логику на стороне сервера.** Запускать код, который не должен быть виден клиенту.
- **Доступ к пакетам npm.** [Агент Antigravity](https://antigravity.google/docs/agent?hl=ru) может устанавливать и использовать пакеты из обширной экосистемы npm.
- **Работа с секретами.** Безопасное использование ключей API и учетных данных.

### Использование пакетов npm

Вам не нужно запускать `npm install` вручную. Просто попросите агента добавить функцию, для которой нужен пакет, и он сам установит и импортирует его.

**Пример.** > "Используй `axios`, чтобы получить данные из внешнего API".

## Безопасное управление секретами

Благодаря серверному коду и управлению секретами вы можете создавать приложения, которые взаимодействуют с миром.

### Ключ Gemini API

Когда вы создаете приложение, использующее Gemini API, AI Studio автоматически настраивает `GEMINI_API_KEY` как секрет на стороне сервера. Никаких действий вручную не требуется. Этот ключ можно посмотреть на панели **Секреты** в настройках. Вызовы Gemini API из вашего приложения выполняются с помощью кода на стороне сервера, в котором используется этот ключ, поэтому он никогда не раскрывается в браузере.

### Ключи API сторонних сервисов

Для других сервисов ключи API можно добавить вручную:

- **Сторонние API.** Подключайтесь к таким сервисам, как Stripe, SendGrid, или пользовательским REST API.
- **Базы данных.** Подключайтесь к внешним базам данных (например, через Supabase, Firebase или MongoDB Atlas), чтобы сохранять данные после завершения сеанса.

При создании реальных приложений часто требуется подключение к сторонним сервисам (например, Twilio, Slack или базам данных), для которых нужны ключи API. Вы можете добавить ключи вручную, выполнив следующие действия:

1. **Добавьте секрет.** Перейдите в меню **Settings (Настройки)** в Google AI Studio и найдите раздел Secrets (Секреты).
2. **Хранение ключей.** Добавьте сюда ключи API или секретные токены.
3. **Доступ в коде.** Агент может написать серверный код, который будет безопасно обращаться к этим секретам (обычно через переменные среды), гарантируя, что они никогда не будут раскрыты клиентскому браузеру.

При необходимости агент также покажет в чате карточку с предложением добавить ключи, когда потребуется новый секрет или когда в переменных среды проекта будет обнаружен новый ключ.

### Интеграция с Firebase для базы данных и аутентификации

Благодаря [интеграции с Firebase](https://firebase.google.com/docs/ai-assistance/ai-studio-integration?hl=ru) в Google AI Studio теперь можно легко добавить в приложение базу данных или аутентификацию.
Агент Antigravity может автоматически подготовить и настроить для вас следующие сервисы:

- **База данных Firestore.** Гибкая масштабируемая облачная база данных NoSQL для хранения и синхронизации данных при разработке на стороне клиента и сервера.
- **Firebase Authentication.** Позволяет пользователям безопасно входить в ваше приложение с аккаунтом Google.

Просто попросите агента добавить базу данных в приложение или настроить вход с аккаунтом Google, и он выполнит необходимую настройку и сгенерирует код.
При создании [приложений для Android](https://ai.google.dev/gemini-api/docs/aistudio-android?hl=ru#firebase-integration) интеграция с Firebase также позволяет использовать **Firebase AI Logic** и **Проверку приложений Firebase** для безопасных вызовов Gemini API на стороне клиента.

Начать работу с Firebase можно бесплатно, а затем, когда вам потребуется больше квот или платные функции, перейти на платный аккаунт.

## Google Workspace API

Google AI Studio позволяет создавать приложения, которые подключаются к API Google Workspace, чтобы пользователи могли работать со своими реальными данными: электронными письмами, таблицами, документами, мероприятиями в календаре и многим другим – прямо в вашем приложении. Вам больше не нужно настраивать облачный проект Google Cloud, настраивать OAuth или управлять API вручную.

### Принцип работы

Добавить интеграцию Workspace можно двумя способами:

- **Опишите его в чате.** Просто расскажите агенту, что вам нужно, в чате внизу. Например, *"Создай трекер расходов, который будет сохранять чеки в таблице Google"* или *"Создай панель, на которой будут кратко пересказываться непрочитанные письма в Gmail"*.
- **Выбрать на панели интеграций.** Откройте панель **Интеграции** на боковой панели справа в режиме создания и включите приложение Workspace, которое хотите подключить.

Когда вы добавляете приложение Workspace, AI Studio автоматически:

1. Подключает к приложению необходимый API Google.
2. Генерирует код на стороне сервера для вызова API.
3. Добавляет безопасный процесс входа с аккаунтом Google, чтобы конечные пользователи вашего приложения могли разрешать доступ к своим данным.

### Поддерживаемые приложения

Доступны следующие приложения Google Workspace:

| Для приложений | Что можно создать |
| --- | --- |
| Google Календарь | Просмотр, создание и управление мероприятиями и календарями |
| Google Chat | Чтение чатов и чат-групп и взаимодействие с ними |
| Google Документы | Создание, просмотр, обновление и форматирование документов |
| Google Диск | Как упорядочивать, искать и настраивать файлы и папки |
| Google Формы | Создание опросов, обновление вопросов и получение ответов |
| Gmail | Чтение, отправка и управление контентом электронной почты |
| Google Keep | Как управлять заметками, списками и прикрепленными файлами |
| Google Meet | Планирование видеовстреч и управление ими |
| Контакты | Синхронизация контактов и управление ими |
| Google Таблицы | Чтение, запись и форматирование данных таблицы |
| Google Презентации | Создание и изменение презентаций. |
| Google Задачи | Создание задач и управление ими |

### Аутентификация и разрешения

Вам не нужно настраивать клиенты OAuth, управлять учетными данными или создавать облачный проект Google Cloud. AI Studio сделает все за вас.

Приложения с интегрированными API Workspace используют функцию "Войти с аккаунтом Google" для аутентификации конечных пользователей. Когда пользователь открывает ваше приложение, ему предлагается войти в систему и предоставить определенные разрешения, необходимые вашему приложению (например, доступ только для чтения к календарю или возможность редактировать таблицу). Приложение получает доступ только к данным пользователя, который с ним работает. Каждый пользователь разрешает доступ к своему аккаунту.

### Примеры запросов

Вот несколько идей, как начать работу с интеграциями Workspace:

- *"Создай приложение, которое будет читать мой Google Календарь и составлять черновики писем в Gmail для подготовки к каждой встрече".*
- *"Создай инструмент, который берет документ Google и генерирует на его основе презентацию Google из пяти слайдов".*
- *"Создай трекер расходов, в который я буду загружать чеки, а Gemini будет извлекать из них данные и добавлять новую строку в таблицу Google".*

### Как настроить OAuth

Один из основных вариантов использования управления секретами – настройка OAuth для подключения к другим сайтам или приложениям. Если в запросе есть инструкции по подключению к стороннему приложению, для которого требуется аутентификация OAuth, агент предоставит инструкции по настройке OAuth для этого приложения. В этих инструкциях будут указаны URL обратного вызова, необходимые для настройки приложения OAuth.
URL обратного вызова также можно найти в разделе **Интеграции** на панели настроек.

## Создавайте многопользовательские игры

Среда выполнения полного стека позволяет использовать функции совместной работы в реальном времени.

- **Состояние в реальном времени.** Вы можете попросить агента создать такие функции, как чат, доска для совместной работы или многопользовательская игра.
- **Синхронизированные сеансы.** Сервер управляет состоянием, позволяя нескольким пользователям взаимодействовать с одним и тем же экземпляром приложения в режиме реального времени.

**Пример запроса:** > "Сделай игру многопользовательской, чтобы игроки могли видеть курсоры друг друга".

### Советы по тестированию многопользовательских приложений

Перед развертыванием приложения вы можете протестировать многопользовательский режим двумя способами.

1. Откройте приложение в режиме сборки Google AI Studio на нескольких вкладках. При разработке в режиме сборки ваше приложение находится в контейнере разработки. Открыв приложение в нескольких вкладках, вы сможете имитировать действия нескольких игроков.
2. Поделитесь приложением с другими пользователями, нажав **Поделиться** в правом верхнем углу. Затем скопируйте **URL для общего доступа** на вкладке **Интеграции** в меню **Поделиться** и отправьте его игрокам, которым вы предоставили доступ к приложению.

## Рекомендации

- **Вызовы Gemini API.** Ваш `GEMINI_API_KEY` автоматически настраивается как секрет на стороне сервера. Выполняйте вызовы Gemini API из серверного кода, используя этот ключ. Вы можете посмотреть его на панели **Секреты**.
- **Безопасность секретов.** Всегда используйте Secrets Manager для конфиденциальных ключей.
  Никогда не задавайте их в коде файлов.
- **Разделение ответственности.** Логика пользовательского интерфейса должна находиться в клиентском фреймворке (React/Angular), а бизнес-логика и обработка данных – на стороне сервера.
- **Обработка ошибок.** Убедитесь, что серверный код надежно обрабатывает ошибки, возникающие при вызовах API из внешних источников, чтобы предотвратить сбои в работе приложения.

# Google AI Studio-তে ফুল-স্ট্যাক অ্যাপ ডেভেলপ করুন

Google AI Studio এখন ফুল-স্ট্যাক ডেভেলপমেন্ট সাপোর্ট করে, যা আপনাকে ক্লায়েন্ট-সাইড প্রোটোটাইপের বাইরেও
অ্যাপ্লিকেশন তৈরি করতে দেয়। সার্ভার-সাইড রানটাইমের মাধ্যমে, আপনি গোপন তথ্য ম্যানেজ করতে, এক্সটার্নাল API-তে কানেক্ট করতে এবং রিয়েল-টাইম মাল্টিপ্লেয়ার অভিজ্ঞতা তৈরি করতে পারবেন।

## সার্ভার-সাইড রানটাইম

Google AI Studio অ্যাপ্লিকেশনে এখন সার্ভার-সাইড কম্পোনেন্ট (Node.js) অন্তর্ভুক্ত করা যেতে পারে।
এটি আপনাকে এইসব কাজ করতে দেয়:

- **সার্ভার-সাইড লজিক এক্সিকিউট করা**: এমন কোড রান করা যা ক্লায়েন্টের কাছে
  প্রকাশ করা উচিত নয়।
- **npm প্যাকেজ অ্যাক্সেস করা**: [Antigravity এজেন্ট](https://antigravity.google/docs/agent?hl=bn)
  বিশাল npm ইকোসিস্টেম থেকে প্যাকেজ ইনস্টল ও ব্যবহার করতে পারে।
- **গোপনীয় তথ্য ম্যানেজ করা**: API কী ও ক্রেডেনশিয়াল নিরাপদে ব্যবহার করা।

### npm প্যাকেজ ব্যবহার করুন

আপনাকে ম্যানুয়ালি `npm install` চালাতে হবে না। এজেন্টকে শুধু এমন কার্যকারিতা যোগ করতে বলুন যার জন্য প্যাকেজ প্রয়োজন, এবং এটি ইনস্টলেশন এবং ইম্পোর্ট ম্যানেজ করবে।

**উদাহরণ**: > "এক্সটার্নাল API থেকে ডেটা ফেচ করতে `axios` ব্যবহার করো।"

## নিরাপদে সিক্রেট ম্যানেজ করুন

সার্ভার-সাইড কোড এবং সিক্রেট ম্যানেজমেন্টের মাধ্যমে, আপনি এখন এমন অ্যাপ তৈরি করতে পারবেন যা
বিশ্বের সাথে ইন্টার‍্যাক্ট করে।

### Gemini API key

আপনি যখন Gemini API ব্যবহার করে এমন একটি নতুন অ্যাপ তৈরি করেন, তখন AI Studio অটোমেটিক
আপনার `GEMINI_API_KEY`-কে সার্ভার-সাইড সিক্রেট হিসেবে কনফিগার করে — কোনও ম্যানুয়াল সেটআপের
প্রয়োজন নেই। আপনি সেটিংসের **সিক্রেট** প্যানেলে এই 'কী' দেখতে পাবেন। আপনার
অ্যাপের Gemini API কল এই 'কী' ব্যবহার করে সার্ভার-সাইড কোড থেকে করা হয়, তাই
এটি ব্রাউজারে কখনই প্রকাশ করা হয় না।

### থার্ড-পার্টি API key

অন্যান্য পরিষেবার জন্য, আপনি ম্যানুয়ালি API কী যোগ করতে পারবেন:

- **থার্ড-পার্টি API**: Stripe, SendGrid বা কাস্টম REST API-এর মতো পরিষেবার সাথে কানেক্ট করুন।
- **ডেটাবেস**: সেশনের পরেও ডেটা সেভ করে রাখতে এক্সটার্নাল ডেটাবেসের (যেমন, Supabase, Firebase,
  বা MongoDB Atlas-এর মাধ্যমে) সাথে কানেক্ট করুন।

বাস্তব-জগতের অ্যাপ তৈরি করার সময়, আপনাকে প্রায়ই থার্ড-পার্টি পরিষেবার (যেমন Twilio, Slack বা ডেটাবেস) সাথে কানেক্ট করতে হয়, যার জন্য API কী প্রয়োজন। আপনি নিম্নলিখিত ধাপগুলি অনুসরণ করে
ম্যানুয়ালি 'কী' যোগ করতে পারবেন:

1. **সিক্রেট যোগ করা**: Google AI Studio-তে **সেটিংস** মেনুতে যান এবং
   সিক্রেট বিভাগটি খুঁজুন।
2. **আপনার 'কী' স্টোর করুন**: এখানে আপনার API key বা গোপন টোকেন যোগ করুন।
3. **কোডে অ্যাক্সেস**: এজেন্ট সার্ভার-সাইড কোড লিখতে পারে যা এই
   গোপনীয় তথ্য নিরাপদে অ্যাক্সেস করে (সাধারণত এনভায়রনমেন্ট ভেরিয়েবলের মাধ্যমে), যাতে এগুলি
   কখনও ক্লায়েন্ট-সাইড ব্রাউজারে প্রকাশ না পায়।

প্রয়োজন হলে, এজেন্ট চ্যাটে একটি কার্ডও দেখাবে যা আপনাকে নতুন সিক্রেট প্রয়োজন হলে বা প্রোজেক্টের env ভেরিয়েবলে নতুন কী শনাক্ত করা হলে, কী যোগ করার জন্য প্রম্পট করবে।

### ডেটাবেস ও যাচাইকরণের জন্য Firebase ইন্টিগ্রেশন

Google AI Studio এখন
[Firebase ইন্টিগ্রেশন](https://firebase.google.com/docs/ai-assistance/ai-studio-integration?hl=bn)-এর মাধ্যমে আপনার অ্যাপে ডেটাবেস বা যাচাইকরণ যোগ করা সহজ করে তোলে।
Antigravity এজেন্ট আপনার জন্য নিম্নলিখিত পরিষেবাগুলি অটোমেটিক
প্রভিশন ও সেট-আপ করতে পারে:

- **Firestore ডেটাবেস**: ক্লায়েন্ট ও সার্ভার-সাইড ডেভেলপমেন্টের জন্য ডেটা স্টোর ও সিঙ্ক করতে
  একটি ফ্লেক্সিবল, স্কেলেবল NoSQL ক্লাউড ডেটাবেস।
- **Firebase Authentication**: "Google-এর মাধ্যমে সাইন-ইন করুন" ফ্লো ব্যবহার করে আপনার ব্যবহারকারীদের নিরাপদে আপনার অ্যাপ্লিকেশনে সাইন-ইন করার অনুমতি দিন।

এজেন্টকে শুধু "আমার অ্যাপে একটি ডেটাবেস যোগ করো" বা "Google Sign-in সেট-আপ করো" বলুন,
এবং এটি আপনার জন্য প্রয়োজনীয় কনফিগারেশন এবং কোড জেনারেশন ম্যানেজ করবে।
[Android অ্যাপ](https://ai.google.dev/gemini-api/docs/aistudio-android?hl=bn#firebase-integration) তৈরি করার সময়,
Firebase ইন্টিগ্রেশন, সুরক্ষিত ক্লায়েন্ট-সাইড Gemini API কলের জন্য **Firebase AI Logic** এবং **Firebase App
Check**-এরও ব্যবস্থা করে।

Firebase আপনাকে ফ্রিতে শুরু করতে দেয় এবং আপনি যখনই আরও কোটা বা পেড ফিচার ব্যবহার করার জন্য প্রস্তুত হন, তখন ঐচ্ছিকভাবে একটি পেড অ্যাকাউন্টের মাধ্যমে স্কেল করতে পারেন।

## Google Workspace API

Google AI Studio আপনাকে এমন অ্যাপ তৈরি করতে দেয় যা Google Workspace API-এর সাথে কানেক্ট করে, যাতে
আপনার ব্যবহারকারীরা তাদের আসল ডেটা নিয়ে কাজ করতে পারেন: ইমেল, স্প্রেডশিট, ডকুমেন্ট,
ক্যালেন্ডার ইভেন্ট এবং আরও অনেক কিছু, সবই আপনার অ্যাপের মধ্যে। আপনাকে আর Google Cloud প্রোজেক্ট সেট-আপ করতে, OAuth কনফিগার করতে বা ম্যানুয়ালি আপনার API ম্যানেজ করতে হবে না।

### এটি কীভাবে কাজ করে

আপনি দুটি উপায়ে Workspace ইন্টিগ্রেশন যোগ করতে পারবেন:

- **চ্যাট প্যানেলে এটির বিবরণ দিন**: আপনি কী চান তা নিচের চ্যাট প্যানেলে এজেন্টকে বলুন। যেমন, *"এমন একটি খরচ ট্র্যাক করার টুল তৈরি করো যা আমার Google Sheet-এ রসিদ লগ করে"* অথবা *"এমন একটি ড্যাশবোর্ড তৈরি করো যা আমার না পড়া Gmail মেসেজের সারসংক্ষেপ দেখায়।"*
- **ইন্টিগ্রেশন প্যানেল থেকে বেছে নিন**: বিল্ড মোডের ডানদিকের সাইডবারে **ইন্টিগ্রেশন** প্যানেল খুলুন এবং আপনি যে Workspace অ্যাপ কানেক্ট করতে চান সেটি চালু করুন।

আপনি Workspace অ্যাপ যোগ করলে, AI Studio অটোমেটিক:

1. আপনার অ্যাপের জন্য প্রয়োজনীয় Google API কানেক্ট করে।
2. API কল করার জন্য সার্ভার-সাইড কোড জেনারেট করে।
3. একটি সুরক্ষিত "Google-এর মাধ্যমে সাইন-ইন করুন" ফ্লো যোগ করে যাতে আপনার অ্যাপের ব্যবহারকারীরা
   তাদের নিজস্ব ডেটা অ্যাক্সেস করার অনুমতি দিতে পারেন।

### যাচাইকরণ এবং অনুমতি

বিল্ডার হিসেবে, আপনাকে OAuth ক্লায়েন্ট কনফিগার করতে, ক্রেডেনশিয়াল ম্যানেজ করতে
বা Google Cloud প্রোজেক্ট সেট-আপ করতে হবে না। AI Studio আপনার জন্য এই সব কিছু ম্যানেজ করে।

Workspace API ইন্টিগ্রেট করা অ্যাপ, ব্যবহারকারীদের যাচাই করতে "Google-এর মাধ্যমে সাইন-ইন করুন" ফিচার ব্যবহার করে। কোনও ব্যবহারকারী আপনার অ্যাপ খুললে, তাকে সাইন-ইন করতে এবং আপনার অ্যাপের জন্য প্রয়োজনীয় নির্দিষ্ট অনুমতি (যেমন, তার ক্যালেন্ডারে শুধু পড়ার অ্যাক্সেস বা স্প্রেডশিট এডিট করার ক্ষমতা) দিতে প্রম্পট করা হয়। আপনার অ্যাপ শুধু সেই ব্যক্তির ডেটা অ্যাক্সেস করে
যে এটি ব্যবহার করছে। প্রত্যেক ব্যবহারকারী তার নিজের অ্যাকাউন্টে অ্যাক্সেস অনুমোদন করেন।

### প্রম্পটের উদাহরণ

Workspace ইন্টিগ্রেশন শুরু করার জন্য এখানে কিছু আইডিয়া দেওয়া হল:

- *"এমন একটি অ্যাপ তৈরি করো যা আমার Google Calendar পড়ে এবং প্রতিটি মিটিংয়ের জন্য
  Gmail-এ প্রস্তুতিমূলক ইমেল ড্রাফ্ট করে।"*
- *"এমন একটি টুল তৈরি করো যা Google Doc থেকে তথ্য নিয়ে Google Slides-এ ৫-স্লাইডের একটি সারসংক্ষেপ
  প্রেজেন্টেশন তৈরি করে।"*
- *"এমন একটি খরচ ট্র্যাক করার টুল তৈরি করো যেখানে আমি রসিদ আপলোড করলে, Gemini তার থেকে
  বিবরণ বের করে নেবে এবং আমার Google Sheet-এ একটি নতুন রোতে তা লগ করবে।"*

### OAuth সেট-আপ করা

সিক্রেট ম্যানেজমেন্টের একটি মূল ব্যবহার হল অন্যান্য ওয়েবসাইট বা অ্যাপের সাথে কানেক্ট করার জন্য OAuth সেট-আপ করা। আপনার প্রম্পটে OAuth যাচাইকরণ প্রয়োজন এমন কোনও থার্ড-পার্টি অ্যাপের সাথে কানেক্ট করার নির্দেশাবলী থাকলে, এজেন্ট সেই অ্যাপ্লিকেশনের জন্য কীভাবে OAuth সেট-আপ করতে হবে তার নির্দেশাবলী প্রদান করবে। এইসব নির্দেশাবলীতে
আপনার OAuth অ্যাপ্লিকেশন কনফিগার করার জন্য প্রয়োজনীয় কলব্যাক URL অন্তর্ভুক্ত থাকবে।
এছাড়াও, আপনি সেটিংস প্যানেলের **ইন্টিগ্রেশন** বিকল্পে কলব্যাক URL খুঁজে পাবেন।

## মাল্টিপ্লেয়ার অভিজ্ঞতা তৈরি করুন

ফুল-স্ট্যাক রানটাইম রিয়েল-টাইম কোলাবরেশন ফিচার চালু করে।

- **রিয়েল-টাইম স্টেট**: আপনি এজেন্টকে "লাইভ চ্যাট," "কোলাবোরেটিভ হোয়াইটবোর্ড" বা "মাল্টিপ্লেয়ার গেম"-এর মতো ফিচার তৈরি করতে বলতে পারেন।
- **সিঙ্ক করা সেশন**: সার্ভার স্টেট ম্যানেজ করে, একাধিক ব্যবহারকারীকে
  রিয়েল-টাইমে একই অ্যাপ্লিকেশন ইনস্ট্যান্সের সাথে ইন্টার‍্যাক্ট করার অনুমতি দেয়।

**প্রম্পটের উদাহরণ**: > "এটি এমন একটি মাল্টিপ্লেয়ার গেম হিসেবে তৈরি করো যেখানে প্লেয়াররা একে অপরের কার্সর দেখতে পাবে।"

### মাল্টিপ্লেয়ার অ্যাপ টেস্ট করার ব্যাপারে পরামর্শ

আপনার অ্যাপ ডিপ্লয় করার আগে আপনি দুটি উপায়ে মাল্টিপ্লেয়ার মোড পরীক্ষা করতে পারেন।

1. একাধিক ট্যাবে Google AI Studio বিল্ড মোডে আপনার অ্যাপ খুলুন। বিল্ড মোডে
   ডেভেলপ করার সময়, আপনার অ্যাপ একটি ডেভ কন্টেনারে থাকে। একাধিক ট্যাবে
   অ্যাপ খুললে, আপনার অ্যাপ ব্যবহার করে একাধিক প্লেয়ারকে সিমুলেট করতে পারবেন।
2. উপরে ডানদিকে **শেয়ার করুন** মেনু ব্যবহার করে অন্যদের সাথে অ্যাপ শেয়ার করুন।
   তারপর, আপনি যাদের সাথে অ্যাপ শেয়ার করেছেন, তাদের সাথে অ্যাপ ব্যবহার করতে, **শেয়ার করুন** মেনুর **ইন্টিগ্রেশন** ট্যাব থেকে **শেয়ার করা URL** ব্যবহার করুন।

## পেশাদার পদ্ধতি

- **Gemini API কল**: আপনার `GEMINI_API_KEY` অটোমেটিক সার্ভার-সাইড সিক্রেট হিসেবে কনফিগার করা হয়। এই 'কী' ব্যবহার করে আপনার সার্ভার-সাইড কোড থেকে Gemini API কল করুন। আপনি এটি **সিক্রেট** প্যানেলে দেখতে পাবেন।
- **সিক্রেট নিরাপত্তা**: সংবেদনশীল কী-এর জন্য সবসময় সিক্রেট ম্যানেজার ব্যবহার করুন।
  আপনার ফাইলে কখনই এগুলি হার্ডকোড করবেন না।
- **সমস্যা আলাদা করা**: আপনার UI লজিক ক্লায়েন্ট-সাইড ফ্রেমওয়ার্কে (React/Angular)
  এবং আপনার বিজনেস লজিক/ডেটা হ্যান্ডলিং সার্ভার সাইডে রাখুন।
- **সমস্যা ম্যানেজ করা**: অ্যাপ যাতে ক্র্যাশ না করে তার জন্য আপনার সার্ভার-সাইড কোড যাতে এক্সটার্নাল API কল থেকে আসা সমস্যা
  ম্যানেজ করতে পারে তা নিশ্চিত করুন।

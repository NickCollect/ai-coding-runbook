# Экспериментальная функция Lyria RealTime

Экспериментальный движок для высокоточного синтеза музыки, предлагающий инновационные возможности для создания и преобразования аудиоконтента. Lyria RealTime лучше всего подходит для написания песен с помощью ИИ, создания уникальных инструментальных партий и творческих рабочих процессов, требующих глубокого контроля над мелодией и ритмом, без вокала.

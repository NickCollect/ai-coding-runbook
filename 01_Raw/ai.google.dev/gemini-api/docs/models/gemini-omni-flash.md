# Gemini Omni Flash

Gemini Omni Flash 是一款预览版模型，旨在实现快速的对话式视频生成和编辑。它擅长将文字和图片转换为视频，让您可以通过自然语言对话使用 Interactions API 来优化和编辑生成的视频。

[在 Google AI Studio 中试用](https://aistudio.google.com?model=gemini-omni-flash-preview&hl=zh-cn)

## 文档

如需全面了解功能和特性，请访问 [Gemini Omni Flash](https://ai.google.dev/gemini-api/docs/omni?hl=zh-cn) 页面。

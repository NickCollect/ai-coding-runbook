# Modello di anteprima Gemini Embedding 2

Il nostro primo modello di embedding multimodale, che fornisce una mappatura numerica efficiente di testo, immagini, video, audio e PDF in un unico spazio di embedding unificato. Il modello Gemini Embedding 2 è ideale per la ricerca semantica cross-modale, il recupero di documenti e i sistemi di suggerimento che richiedono calcoli di somiglianza rapidi e scalabili su set di dati multimodali di grandi dimensioni.

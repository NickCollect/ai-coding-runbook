# Paket Google AI

Gunakan langganan AI Google Anda di AI Studio.

Paket langganan Google AI Pro dan Ultra memberikan akses model yang lebih besar dan peningkatan batas kapasitas untuk pembuatan prototipe dan pengembangan di AI Studio dibandingkan dengan paket gratis.

Untuk mendaftar paket Google AI, Anda dapat melakukan upgrade langsung dari dalam Google AI Studio dengan mengklik tombol **Upgrade** di menu navigasi kiri. Atau, Anda dapat mendaftar dengan membuka halaman
[Paket Google AI](https://one.google.com/about/google-ai-plans/?hl=id).

## Ringkasan

Langganan Google AI Pro dan Ultra memungkinkan developer membuka model berbayar
dan batas kapasitas yang lebih tinggi di Playground Google AI Studio dan fitur
seperti Asisten Kode dalam [mode Build](https://ai.google.dev/gemini-api/docs/aistudio-build-mode?hl=id)
untuk pengkodean vibe. Pelanggan menerima alokasi kuota harian dasar
yang lebih tinggi daripada paket gratis untuk digunakan di seluruh antarmuka
[Playground](https://aistudio.google.com/prompts/new_chat?hl=id) dan
[Build](https://aistudio.google.com/apps?hl=id). Batas harian diberlakukan menggunakan reset, bukan jendela waktu bergulir, sehingga memastikan pengalaman pengembangan yang lancar sebelum beralih ke pengembangan skala produksi dengan Penagihan Cloud.

| Paket | Penggunaan AI Studio | Akses dan manfaat model |
| --- | --- | --- |
| **Gratis** | Kuota sedang | Batas dan akses dasar, dengan opsi untuk melakukan upgrade agar mendapatkan lebih banyak. |
| **AI Pro** | Kuota lebih tinggi | Akses ke model premium seperti Gemini Pro, Nano Banana, dan Lyria. |
| **AI Ultra** | Kuota tertinggi | Batas tertinggi untuk pembuatan prototipe, pengembangan, dan model canggih. |

## Penggunaan Gemini API

Jika kuota langganan dasar harian habis di AI Studio, Anda dapat melanjutkan alur kerja menggunakan kunci Gemini API dengan Penagihan Cloud yang diaktifkan untuk penggunaan Gemini API langsung dengan model bayar sesuai penggunaan.
Penggunaan Gemini API untuk project dan kunci API dapat diamati di
[Dasbor AI Studio](https://aistudio.google.com/projects?hl=id).

Pelanggan dengan akun developer Gemini API dan akun yang mengaktifkan Penagihan Cloud berhak menerima kredit Cloud bulanan dari [Google Developer Program](https://developers.google.com/program?hl=id) untuk layanan Cloud, termasuk Gemini API. Penggunaan dan penagihan prabayar dan pascabayar tetap tidak berubah. Untuk pengguna dengan penagihan prabayar, saldo berbayar yang lebih besar dari $0 diperlukan di AI Studio untuk mengaktifkan kredit promosi. Kredit Google Cloud yang memenuhi syarat, jika ada, akan diterapkan terlebih dahulu.
[Pelajari lebih lanjut](https://ai.google.dev/gemini-api/docs/billing?hl=id#billing-plans).

Integrasi langganan AI Google menurunkan hambatan untuk eksperimen dan pengembangan lanjutan. Namun, untuk produksi
deployment dalam skala besar, project Google Cloud, [Paket Pemula Google Cloud](https://cloud.google.com/blog/topics/developers-practitioners/the-starter-tier-for-google-ai-studio-explained?hl=id),
dan kunci Gemini API adalah jalur yang direkomendasikan.

## Batasan dan kompatibilitas

- **UI AI Studio saja:** Manfaat paket Google AI untuk penggunaan developer hanya berlaku dalam antarmuka web Google AI Studio. Penggunaan Gemini API secara langsung (seperti menggunakan kunci API atau aplikasi eksternal) ditagih dan dikelola secara terpisah. Namun, Anda dapat menggunakan langganan di seluruh produk Google
  lainnya (lihat [Paket Google AI](https://one.google.com/about/google-ai-plans/?hl=id)).
- **Berbeda dengan penagihan API:** Paket Google AI untuk AI Studio terpisah
  dari [tingkat penggunaan Gemini API](https://ai.google.dev/gemini-api/docs/billing?hl=id), yang mencakup
  penggunaan API pengembangan dan produksi.
- **Kredit Google One:** [Kredit AI Google One](https://support.google.com/googleone/answer/16287445?hl=id) adalah
  sistem kredit terpisah yang tidak didukung dalam AI Studio dan tidak
  tumpang-tindih dengan kredit Google Cloud.
- **Akses agen:** Akses ke agen (Deep Research dan Antigravity Preview)
  dalam AI Studio tidak disertakan dalam paket Google AI dan memerlukan
  [kunci API berbayar](https://ai.google.dev/gemini-api/docs/billing?hl=id#setup-billing).

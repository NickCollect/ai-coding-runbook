# การบันทึกและการแชร์ข้อมูล

หน้านี้อธิบายถึงการจัดเก็บและการจัดการ[บันทึกของ Gemini API](https://ai.google.dev/gemini-api/docs/logs-datasets?hl=th) ซึ่งเป็นข้อมูล API ที่นักพัฒนาแอปเป็นเจ้าของ
จากการเรียก Gemini API ที่รองรับสำหรับโปรเจ็กต์ที่เปิดใช้การเรียกเก็บเงิน บันทึก
ครอบคลุมกระบวนการทั้งหมดตั้งแต่คำขอของผู้ใช้ไปจนถึงคำตอบของโมเดล
บันทึกเหล่านี้ซึ่งเป็นแบบส่วนตัวสำหรับโปรเจ็กต์ Google Cloud จะแยกจากบันทึกใดๆ ที่เก็บไว้เพื่อวัตถุประสงค์ในการ[ตรวจสอบการละเมิด](https://ai.google.dev/gemini-api/docs/usage-policies?hl=th)เท่านั้น

## ข้อมูลที่แชร์ได้

ในฐานะเจ้าของโปรเจ็กต์ คุณสามารถเลือกที่จะเลือกใช้การบันทึกการเรียกใช้ Gemini API
เพื่อใช้เอง หรือเพื่อส่งความคิดเห็นและแชร์กับ Google เพื่อช่วยเราปรับปรุงโมเดลอย่างต่อเนื่อง

การเปิดใช้การบันทึกจะช่วยให้เราสร้างระบบ AI ที่ยังคงมีคุณค่าสำหรับนักพัฒนาซอฟต์แวร์ในสาขาและกรณีการใช้งานต่างๆ ได้โดยเลือกที่จะมีส่วนร่วมด้วยการให้ข้อมูลต่อไปนี้เพื่อการปรับปรุงผลิตภัณฑ์และการฝึกโมเดล

- **ชุดข้อมูล:** ใช้ส่วนติดต่อบันทึกและชุดข้อมูลของ Google AI Studio เพื่อ
  เลือกบันทึก (คำขอ คำตอบ ข้อมูลเมตา ฯลฯ) ที่สนใจจาก
  การเรียก Gemini API ที่รองรับ ซึ่งมีส่วนร่วมผ่านการรวมไว้ในชุดข้อมูล โดยมี
  ตัวเลือกในการเลือกไม่ใช้ระหว่างการสร้างชุดข้อมูล
- **ความคิดเห็น:** เมื่อตรวจสอบบันทึก คุณจะแสดงความคิดเห็นได้ ซึ่งรวมถึงการให้คะแนนชอบและไม่ชอบ รวมถึงความคิดเห็นที่เป็นข้อความที่คุณระบุ

เมื่อคุณแชร์ชุดข้อมูลกับ Google ระบบจะประมวลผลบันทึกในชุดข้อมูลนั้น ซึ่งรวมถึงคำขอและการตอบกลับ ตาม[ข้อกำหนด](https://developers.google.com/terms?hl=th)สำหรับ
"[บริการที่ไม่เสียค่าใช้จ่าย](https://ai.google.dev/gemini-api/terms?hl=th#data-use-unpaid)"
ซึ่งหมายความว่าระบบอาจใช้ชุดข้อมูลเพื่อพัฒนาและปรับปรุงผลิตภัณฑ์ บริการ และเทคโนโลยีแมชชีนเลิร์นนิงของ Google รวมถึงการปรับปรุงและ
การฝึกโมเดลของเรา **โปรดอย่าระบุข้อมูลส่วนตัว ข้อมูลที่ละเอียดอ่อน หรือข้อมูลลับ**

## วิธีที่เราใช้ข้อมูลของคุณ

ระบบจะเก็บรักษาบันทึกไว้เป็นระยะเวลาสูงสุดเริ่มต้นที่ 55 วัน หลังจากระยะเวลานี้ ระบบจะทำเครื่องหมายบันทึกเพื่อลบโดยอัตโนมัติ คุณอัปเดตระยะเวลาเก็บรักษาพื้นที่เก็บข้อมูลสำหรับโปรเจ็กต์ได้ใน AI Studio เพื่อทำเครื่องหมายบันทึกสำหรับการลบโดยอัตโนมัติหลังจากผ่านไป 7, 14, 28 หรือ 55 วัน

คุณสร้าง[ชุดข้อมูล](https://ai.google.dev/gemini-api/docs/logs-datasets?hl=th)เพื่อเก็บรักษาบันทึกของ
ความสนใจเกินกว่าระยะเวลาเก็บรักษาที่กำหนดไว้สำหรับ Use Case ดาวน์สตรีมและ
การมีส่วนร่วมที่ไม่บังคับในการปรับปรุงโมเดลได้ บันทึกที่จัดเก็บไว้ในชุดข้อมูลจะไม่มี
ระยะเวลาเก็บรักษาที่กำหนด

โดยค่าเริ่มต้น เนื่องจากระบบจะบันทึกได้เฉพาะโปรเจ็กต์ที่เปิดใช้การเรียกเก็บเงิน
พรอมต์และการตอบกลับภายในบันทึกจึงไม่ได้ใช้เพื่อปรับปรุงหรือ
พัฒนาผลิตภัณฑ์ตาม[ข้อกำหนด](https://developers.google.com/terms?hl=th)
เกี่ยวกับการใช้ข้อมูล

หากเลือกแชร์ชุดข้อมูลของบันทึกกับ Google ชุดข้อมูลเหล่านั้นจะใช้เป็นข้อมูลการสาธิตในโลกแห่งความเป็นจริงเพื่อทำความเข้าใจความหลากหลายของโดเมนและบริบทที่ใช้ระบบและแอปพลิเคชัน AI ได้ดียิ่งขึ้น เราอาจใช้ข้อมูลนี้เพื่อปรับปรุงคุณภาพของโมเดล รวมถึงใช้เป็นข้อมูลในการฝึกและประเมินโมเดลและบริการในอนาคต เราจะประมวลผลข้อมูลนี้ตามข้อกำหนดในการใช้ข้อมูล
สำหรับ[บริการที่ไม่มีค่าใช้จ่าย](https://ai.google.dev/gemini-api/terms?hl=th#data-use-unpaid)

ดังนั้น เจ้าหน้าที่ตรวจสอบอาจอ่าน ใส่คำอธิบายประกอบ และประมวลผลอินพุตและเอาต์พุตของ API ที่คุณแชร์ ก่อนที่จะใช้ข้อมูลเพื่อปรับปรุงโมเดล Google จะทำตามขั้นตอน
เพื่อปกป้องความเป็นส่วนตัวของผู้ใช้ในกระบวนการนี้ ซึ่งรวมถึงการยกเลิกการเชื่อมต่อ
ข้อมูลนี้กับบัญชี Google, คีย์ API และโปรเจ็กต์ Cloud ก่อนที่เจ้าหน้าที่จะเห็นหรือใส่คำอธิบายประกอบ

## สิทธิ์ของข้อมูล

การเลือกใช้เพื่อแชร์ข้อมูล API เป็นการยืนยันว่าคุณมีสิทธิ์ที่จำเป็นเพื่อให้ Google ประมวลผลและใช้ข้อมูลตามที่อธิบายไว้ในเอกสารประกอบนี้ **โปรดอย่าส่งบันทึกที่มีข้อมูลที่ละเอียดอ่อน เป็นความลับ หรือเป็นกรรมสิทธิ์ซึ่งได้มาจากบริการแบบชำระเงิน**
ใบอนุญาตที่คุณมอบให้ Google ภายใต้ส่วน "[การส่งเนื้อหา](https://developers.google.com/terms?hl=th#b_submission_of_content)"
ในข้อกำหนดของ API ยังครอบคลุมถึงเนื้อหาใดๆ (เช่น พรอมต์ รวมถึงคำสั่งของระบบที่เกี่ยวข้อง เนื้อหาที่แคชไว้ และไฟล์ต่างๆ เช่น รูปภาพ วิดีโอ หรือเอกสาร) ที่คุณส่งไปยังบริการและคำตอบที่สร้างขึ้นด้วย ในขอบเขตที่กฎหมายที่เกี่ยวข้องกำหนดให้เราใช้

## การแชร์ข้อมูลและความคิดเห็น

AI Studio ได้โดยเลือกแชร์ข้อมูลของคุณเป็นตัวอย่าง ซึ่งจะช่วยให้เรา
ปรับปรุงโมเดลอย่างต่อเนื่องในบริบทต่างๆ และสร้างระบบ AI ที่
ยังคงมีคุณค่าต่อนักพัฒนาซอฟต์แวร์ในสาขาและกรณีการใช้งานต่างๆ
